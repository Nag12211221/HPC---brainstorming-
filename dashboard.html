    About this file

    This is a fully standalone, offline build of the HPC Predictive Quality Platform. The simulation, drift detector, dual failure models, ROI calculator, alert center and case study all run in your browser — there is no server, no CDN, and no network call.

    • Just open dashboard.html in any modern browser. Works from a USB stick or email attachment.
    • Share state via 🔗 Share link (config + selection encoded in the URL hash).
    • Export full snapshot as JSON or fleet table as CSV. Print to PDF for hand-off reports.
    • State persists between sessions in localStorage.
    HPC Predictive Quality Platform · standalone build All computation runs locally in your browser. No external dependencies.
